# GEMINI.md (The Index)

## Project Summary
**Markdown Beautifier** is a premium, single-page web application designed to render raw Markdown into highly aesthetic documents using the Antigravity design system.

## Tech Stack
-   **Frontend:** HTML5, Vanilla CSS, JavaScript.
-   **Libraries:** CodeMirror 5 (Editor), Marked.js (Markdown parsing), Lucide Icons.
-   **Design:** Custom "Antigravity" tokens, Inter/JetBrains Mono typography.
